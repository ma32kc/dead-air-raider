# Third-party assets

Characters, walls and crates in the demo are built from Unity primitives as prefabs for this test.

## Textures

Files live in `Assets/_DeadAir/Art/Textures`. All from [Poly Haven](https://polyhaven.com), CC0.

| File | Use | Source |
| --- | --- | --- |
| `Ground_*` | Crater ground | [Red Laterite Soil Stones](https://polyhaven.com/a/red_laterite_soil_stones) |
| `Rock_*` | Rocks | [Red Mud Stones](https://polyhaven.com/a/red_mud_stones) |
| `ShutterMetal_*` | Metal walls | [Painted Metal Shutter](https://polyhaven.com/a/painted_metal_shutter) |
| `OchrePaint_*` | Crates | [Rusty Metal 03](https://polyhaven.com/a/rusty_metal_03) |
| `RustyMetalSheet_*` | Barrels, scrap, oxygen tank, raider | [Rusty Metal Sheet](https://polyhaven.com/a/rusty_metal_sheet) |
| `SuitPaint_*` | Hero suit (albedo desaturated to faded white) | [Rusty Metal 02](https://polyhaven.com/a/rusty_metal_02) |

`HazardStripes_Albedo.png` and the UI sprites in `Art/UI` (visor vignette, crosshair) are drawn for this project.
